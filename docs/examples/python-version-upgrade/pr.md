# feat(crawler-runtime): 파이썬 실행 버전 업그레이드

상태: 원격 Issue와 구현이 없어 PR 생성 조건 미충족.

## Issue

실제 원격 Issue 참조 확인 후 기입한다. 연결 Issue가 PR이 아닌 실제 Issue인지 의도·영향·달성 조건과 대조한다.

## 변경 의도와 범위

확정한 목표 Python으로 실행 환경을 정렬하고 기존 수집 동작을 유지한다. 실제 변경 파일과 제외 범위는 구현 이후 요약한다.

## 구현과 문서

[plan](plan.md)·[todos](task-02-runtime-upgrade.md)·[handoff](handoff.md)에 상세 배경과 결과를 기록한다. 원격 PR에는 실제 접근 가능한 commit/branch 문서 링크로 교체하고 핵심만 요약한다.

## 검증 상태

TC-01~04: not-run. 테스트 통과·정책 준수·운영 배포를 주장하지 않는다. 실제 결과와 검토 HEAD를 연결한 뒤 리뷰를 요청한다.

## 위험·미결정

목표 버전·실제 실행/배포 경로와 호환성 조사가 필요하다. dev 대상 개발 통합이며 prod 배포·태그 발행·머지는 별도 승인 범위를 따른다.
