# 파이썬 버전 업그레이드 계획

## 요청

> dmp.crawler 프로젝트 파이썬 버전 업그레이드가 필요해. issue-create와 plan-create로 준비하고 진행해줘.

- 해석: Python 실행 버전을 올리고 기존 수집 동작을 유지한다. 선언 변경에 그치지 않고 의존성·실행 환경·동작 회귀까지 확인한다.
- 남은 결정: 목표 버전, 실제 배포 경로 (결정과 변경 기록 참고)

## 현재 동작과 변경 이유

| 현재 동작 | 근거 위치 | 바꿀 결과 |
| --- | --- | --- |
| 현재 Python 버전·설치 방법 미확인 | 01 단계 조사 산출물 | 목표 버전으로 실행 |
| 컨테이너·CI 실행 환경 미확인 | 01 단계 조사 산출물 | 목표 버전과 일치 |

## 범위

| 구분 | 내용 |
| --- | --- |
| 포함 | 런타임 선언·이미지, 의존성 잠금 파일, CI 실행 환경, 관련 호환 코드와 테스트 |
| 제외 | 무관한 수집 로직 변경, 새 기능, 운영 데이터 변경, 승인 없는 배포 |
| 미변경 소비자 | 수집 산출물을 읽는 하위 작업 |
| 호환성·데이터·운영 | 산출물 형식 유지. 운영 데이터 변경 없음 |
