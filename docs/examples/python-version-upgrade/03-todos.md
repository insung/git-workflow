# 03 통합·배포 준비와 PR 인계

가상 미실행 체크리스트. [plan 03 단계](plan.md)를 따른다.

## 수집 동작 회귀와 배포 준비 검증

- [ ] 수집 동작 회귀와 배포 준비 검증
  - [ ] 운영 쓰기 없는 fixture로 산출물 계약을 대조한다
  - [ ] 실제 배포 트리거·사전 점검·롤백 조건을 확인한다
  - [ ] 미실행·실패·인간 결정 항목을 구분해 기록한다

## 커밋·PR과 독립 리뷰 인계

- [ ] 커밋·PR과 독립 리뷰 인계
  - [ ] commit-rule로 요청 범위만 커밋한다
  - [ ] handoff에 실제 HEAD·사례별 테스트 근거를 기록한다
  - [ ] pr-create로 실제 Issue 연결·요약·문서 링크를 준비한다
  - [ ] pr-review에 새 HEAD를 전달하고 사용자 머지 승인을 별도 확인한다

## 검증 checklist

- [ ] plan의 연결 AC/TC와 실제 수행 범위를 대조한다.
- [ ] 명령·환경·대상 커밋·기대/실제 결과를 handoff에 연결한다.
- [ ] 미실행은 not-run이며 체크하지 않는다. 미결정은 사유·다음 행동을 기록한다.
