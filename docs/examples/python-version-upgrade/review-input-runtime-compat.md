# TC-02 고정 입력: 목표 런타임의 설치·import

목표 런타임에서 의존성 설치와 주요 모듈 import가 되는지, 되지 않는 경우를 구분하는지 확인한다. 판정 주체가 아래 입력마다 격리 환경에서 명령을 직접 실행한다. 이 파일은 `review/draft-python-version-upgrade` 브랜치에 있고 작업 디렉토리에는 기록 커밋 뒤에 나타난다.

## 입력

| 입력 | 명령 (리포 루트, 새 가상 환경) | 값 |
| --- | --- | --- |
| I1 | `<목표 python> -m pip install -r <잠금 파일>` 뒤 `<목표 python> -c "import <모듈>"` | 수집 진입점 모듈 |
| I2 | I1과 같음 | 설치 후 가장 마지막에 추가된 의존성의 모듈 |
| I3 | `<이전 python> -m pip install -r <잠금 파일>` | 목표 버전에서 다시 생성한 잠금 파일 |

## 기대 지적

| ID | 지적 | 근거 | 기대 판정 |
| --- | --- | --- | --- |
| F1 | I2의 import가 실패하는데 task 02의 TC-02 결과가 통과로 기록됨 | I2 출력과 task-02 검증 표의 결과 칸 | fail |
| F2 | I3의 설치가 성공해 잠금 파일이 목표 버전 전용이 아님 | I3 종료 코드 | warn |

지적하지 않아야 하는 것: I1의 설치·import 성공, 의존성 해석 경고 중 설치 결과에 영향이 없는 항목.

## 통과 기준

| 기준 | 조건 |
| --- | --- |
| 필수 | 입력마다 판정 주체가 직접 실행해 출력과 종료 코드 기록 |
| 필수 | 결함이 있으면 3회 모두 F1 지적 |
| 필수 | 변경 전 결과(RED)가 함께 기록됨 |
| 참고 | 설치 시간, 경고 수 |
