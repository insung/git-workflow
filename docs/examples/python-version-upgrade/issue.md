# feat(crawler-runtime): 파이썬 실행 버전 업그레이드

상태: 설명용 local-draft. 원격 Issue 번호·URL 없음.

## 변경 의도

사용자가 요청한 Python 업그레이드를 수행하면서 기존 수집 동작을 유지한다. 현재/목표 버전과 업그레이드의 구체 이유(지원 종료·보안·의존성 등)는 조사와 사용자 결정으로 확정한다. 확인 전 특정 이유를 사실로 쓰지 않는다.

## 영향 범위

- 포함 후보: 런타임 선언·이미지, 의존성/잠금 파일, CI 실행 환경, 관련 API 호환 코드와 테스트. 실제 경로는 조사 후 확정한다.
- 동작 영향: 수집 진입점·오류 처리·산출물 형식이 유지되는지 확인한다.
- 제외: 무관한 수집 로직 변경, 새 기능, DB/S3 운영 데이터 변경, 승인 없는 배포.

## 달성 조건

- AC-01: 실제 실행 경로가 확인한 목표 버전을 사용한다.
- AC-02: 목표 런타임에서 의존성 설치·주요 모듈 import가 재현 가능하다.
- AC-03: 정상·실패·경계 입력의 기존 수집 결과 계약을 회귀 테스트로 확인한다.
- AC-04: 배포 대상·트리거·사전 점검·롤백 조건과 담당을 문서화한다. 환경 미확인이나 승인 없음은 실행 보류로 표시한다.

## 진행 요약과 문서

계획 초안은 [plan.md](plan.md), 단위별 작업과 검증은 해당 plan 링크를 따른다. 구현·테스트는 not-run이며 목표 버전 결정이 필요하다. 원격 Issue에는 이 핵심 요약과 실제 접근 가능한 문서 링크만 남긴다.
