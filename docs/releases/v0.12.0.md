# v0.12.0 — AI 답변에 반응한 요청의 맥락 보존

공개 Release name: `v0.12.0`

## AI 답변에 반응한 요청의 맥락 보존

Issue 원문 절에 「좋아. 승인.」 같은 짧은 답이 남을 때, 그 답이 반응한 AI 답변의 요약이 바로 앞에 남는다. Issue만 읽어도 무엇을 승인했는지, 무엇을 물었는지 알 수 있다.

## 변경 사항

### 🚀 기능·개선

- **AI 답변 요약 줄:** 사용자 발화가 직전 AI 답변에 반응했으면 원문 절의 그 인용 바로 앞에 `AI 답변 요약:` 한두 문장을 둔다. 이 줄은 `>` 인용으로 쓰지 않고, AI 답변 전문은 복사하지 않는다. 최초 요청에는 두지 않는다. D번호 결정의 답은 「결정 기록」이 대상을 밝히므로 반복하지 않아도 된다. 기능·버그 템플릿의 원문 절 주석도 같은 규칙을 안내한다. [#83](https://github.com/insung/git-workflow/pull/83)

## 업그레이드 안내

- Claude Code와 Codex에서 플러그인을 0.12.0으로 갱신한 뒤 새 세션을 시작한다.
- 새 규칙은 새로 만들거나 다시 쓰는 Issue에 적용된다. 기존 Issue 본문과 소비 프로젝트의 Issue 템플릿은 자동으로 바뀌지 않는다. 템플릿은 `workflow-init`으로 갱신을 요청할 때 바뀐다.

## 검증

#83에서 패키지 검사와 테스트를 변경 전후로 실행했다. 이번 준비에서 `node --test tests/*.test.mjs`와 `node scripts/check-package.mjs`를 다시 실행했다. 별도 세션이 새 규칙만 읽고 Issue를 쓰는 행동 실행은 하지 않았다. 자세한 AC·명령·결과는 위 PR에 있다.
