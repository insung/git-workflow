# Git Workflow 개발 이력

이 디렉토리는 플러그인을 실제로 설계·구현·검증한 기록이다. 설명용 예시와 구분하기 위해 기존 docs/issues·docs/superpowers·docs/git-workflows 및 docs/testing의 실행 관찰을 모았다. 내용과 당시 상태를 보존하며 과거의 Wiki 기능·검증 개수·미커밋 상태를 현재 계약으로 읽지 않는다.

- [초기 구현 계획](initial/plan.md)
- [초기 설계](initial/design.md)
- [초기 검증](initial/verification.md), [가상 입력 관찰 기록](initial/issue-review-scenarios.md)
- [문서 계약 계획](contracts/plan.md), [후속 검증 기록](contracts/validation.md)

현재 사용법과 흐름은 [한국어 README](../../../README.ko.md)와 [English README](../../../README.md)에 있다. 새 예제는 [docs/examples](../../examples/README.md)에 둔다. 실제 대상 리포의 향후 작업 경로는 [plan 정본](../../../skills/plan-create/references/plan.md#경로와-준비-조건)을 계속 따른다.
