## 다음 검토·위험·롤백

메인은 Issue → plan 공통 맥락 → diff·task·handoff → 독립 기준·입력 순서로 검토한다. 검토 소스는 4ae4526으로 고정한다. 자체 행동 미실행을 독립 판정으로 덮어쓰지 않고 실제 실행 주체와 입력·횟수·제한을 구분해 기록한다.

현재 상태는 소스 구현 완료·행동 검증 및 독립 판정 대기다. push·PR·머지·설치·기존 AGENTS 적용은 범위 밖이다. 롤백은 두 소스 커밋의 해당 변경만 되돌리며 동시 작업 reset은 하지 않는다.
