시나리오는 새 실행자에게 구현 세션이 만든 공개 요청문과 대상 스킬만 전달한다. 기대 결과·다른 실행 결과·비공개 리뷰 입력은 전달하지 않는다. 메인이 직접 실행·판정한다. RED에서 기존 보존 동작이 통과하면 그대로 기록하며 실패를 강제하지 않는다. 실제 원격 게시·머지 대신 임시 저장소와 모의 실행 기록으로 관찰한다.

## 제외 범위

- 기존 프로젝트 지침 실제 적용, push·PR·머지·설치·Release
- 비공개 검토 기준·고정 입력 열람

## 실행 결과 요약

역할 선언·초기화 안내를 구현했으나 행동 검증 충족은 미완료. 사용자 지시에 따라 추가 검증을 중단한 이력이며 완료 검증으로 표현하지 않음. 이후 실제 종료 이유·원격 상태는 Issue #13에서 확인.

당시 명령은 저장소 루트의 `node --test tests/package.test.mjs`, `node scripts/check-package.mjs`, `git diff --check`를 중심으로 실행했다. 추가 명령·대상 작업본·실행 시각은 plan의 정리 전 기록에서 확인한다. 현재 HEAD의 재검증 결과로 사용하지 않는다.
