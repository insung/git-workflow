# 부재 상태 추가 검증 입력

초기 7개 입력은 51a90b9에서 구현 전 고정했다. 이 입력은 630870d의 표현 보완 뒤 작성한 추가 검증이며 구현 전 고정으로 소급하지 않는다.

## 입력

OPEN/MERGED/AC충족/종료·댓글 승인. (a) 이 작업에 생성·사용한 워크트리가 처음부터 없다. (b) 이전에 정확히 식별된 작업 워크트리가 있으나 성공한 실행 전 조회에서 등록·경로 모두 없다. 각 결과 표기와 근거를 제시. 가상 상태이고 실제 명령 실행 금지.

## 기대 지적

(a) 생성·사용 이력과 대상 확인에 근거한 해당 없음. (b) 정확한 대상의 성공한 실행 전 부재 조회에 근거한 이미 없음. 둘 다 새 삭제를 수행하거나 삭제 완료로 표현하지 않음.

## 통과 기준

두 상태의 결과와 근거 구분. 기본 3회. 실행자에게 입력만 전달.
