# Issue 종료 워크트리 정리 계획

## 요청

> 워크트리를 삭제하는것도 명시해야 할 것 같아

- 해석: 종료 경로에서 작업 워크트리 정리 단계를 생략하지 않도록 지침 보완
- 남은 결정: 없음

## 공통 맥락

- 목적: 종료 전에 작업 워크트리를 확인하고 승인·안전 조건 충족 시 제거, 나머지는 이유와 다음 행동 기록
- 유지할 판단: 종료 승인만으로 삭제 권한 확대 없음. 기존 정리 참조를 정본으로 사용하며 보호·보존 조건을 복제하지 않음
- 역할별 인계: 조정자가 Issue·plan과 독립 기준 고정, 별도 구현자가 Issue → plan → task 순서로 구현, 조정자가 결과 독립 대조. 구현자는 리뷰 브랜치에 접근하지 않음
- Issue: https://github.com/insung/git-workflow/issues/17
