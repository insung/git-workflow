# 고정 사례 직접 적용 검증

- 수행: 부모 검토 주체, 구현자의 자체 입력과 별도로 고정 입력 RV-01~17 사용
- 방식: 변경 전 원문과 변경 후 원문을 읽고 각 입력에 직접 규칙 적용. 표의 API 응답은 mock 입력이며 실제 원격 호출 결과가 아님
- 한계: 별도 모델의 행동 정확도·실제 GitHub 게시·호스트 로딩은 검증하지 않음
- 비교: 변경 전 유지 계약 5건, 새 요구 계약 누락 12건. 변경 후 17건의 기대 경로와 금지 행동 경계를 직접 대조. 이 수치는 모델의 성공률이 아님
- RV-15는 fail·human-review 두 변형을 각각 대조

| 사례 | 변경 전 계약 | 최종 규칙 적용 | 실제 대조 결과 |
| --- | --- | --- | --- |
| RV-01 | 필요 계약 누락 | 요청 확인 → 최신 HEAD·전체 댓글 조회 → 최초 검토 신규 → 본문·URL 재조회 / A 전체 HEAD/pass, AC-01·02, warn, 남은 일, A permalink, 머지 승인 아님. 원문 PR 전용 내용·실행 1~5에 따라 반환 | 직접 대조 통과 |
| RV-02 | 필요 계약 누락 | B 게시 요청 확인 → C1=A/fail 대조 → B 재검토 신규·C1 연결 → 재조회 / C1 보존, B/pass 신규, A 판정·승인은 B에 적용 안 함 | 직접 대조 통과 |
| RV-03 | 필요 계약 누락 | 같은 A의 새 근거·실질 판단 변경 대조 → C1 보존한 신규 → 재조회 / human-review→pass 판단 변화와 새 근거 설명, 기존 기록 수정 안 함 | 직접 대조 통과 |
| RV-04 | 필요 계약 누락 | 수정 요청·자기 댓글 이력 확인 → 같은 증거 URL만 보정 → C1 재조회 / 판정 유지, 같은 행동 승인 재질문 없음, 신규 댓글 없음 | 직접 대조 통과 |
| RV-05 | 필요 계약 누락 | 동일 PR·A·종류·판정·근거·자기 작성 이력 조회 → C1 반환 / 쓰기 없음. 같은 결과의 재실행은 재게시 생략 | 직접 대조 통과 |
| RV-06 | 충족(유지) | 댓글 요청 없음 확인 → 대화 결과 반환 / 과거 PR 생성·머지 승인으로 게시 안 함, review.md 기록 요청도 없음 | 직접 대조 통과 |
| RV-07 | 충족(유지) | 게시 승인 대상 A vs 현 B 대조 → B 재검토 대화 반환 / A 게시 승인 확대 안 함. B 댓글 신규·A 수정 없음 | 직접 대조 통과 |
| RV-08 | 필요 계약 누락 | 신규 요청·조회 → mock 게시 timeout → mock 재조회 C2 일치 확인 → C2 반환 / 재게시 없음, 동일 PR·A·종류·본문 재확인 | 직접 대조 통과 |
| RV-09 | 필요 계약 누락 | mock 게시 timeout → mock 후속 조회도 실패 → 미확인으로 종료 / 성공 단정·재게시 없음, 중복 위험·필요 조회 보고 | 직접 대조 통과 |
| RV-10 | 충족(유지) | 검토 A=실제 A·pass·위험·동일 머지 승인 확인 → 대화 확인 결과 / 댓글 부재는 blocker 아님. fixture의 실제 머지 금지 준수 | 직접 대조 통과 |
| RV-11 | 필요 계약 누락 | 검토 A vs 실제 B 불일치 → pr-review 인계 → 요청된 확인 기록 신규 → 재조회 / 검토 A/실제 B·보류·재검토 명시. A pass·승인을 B에 재사용하지 않음. 보완 후 실행2 예외 적용 | 직접 대조 통과 |
| RV-12 | 충족(유지) | PR 생성 인계 요청만 확인 → 본문·handoff 기본 기록 → pr-review 인계 / 별도 댓글·가짜 검토 pass 없음, 실제 PR 생성은 fixture에서 안 함 | 직접 대조 통과 |
| RV-13 | 충족(유지) | 요청·댓글 조회 → 요약과 링크 준비 중 상태 → 게시 계획·재확인 / untracked/미push 결과의 존재하지 않는 permalink·로컬 URL 없음. 자동 commit/push 없음 | 직접 대조 통과 |
| RV-14 | 필요 계약 누락 | C1 작성 주체·종류·이력 대조 → 인간/다른 workflow C1 제외 → 자기 신규 필요성 판단 / 같은 실행 계정이라고 소유를 추정하지 않음. C1 수정/삭제 없음 | 직접 대조 통과 |
| RV-15 | 필요 계약 누락 | 두 변형 각각 댓글 요청·조회 → AC별 미충족/미확인 요약 → 신규·재확인 / fail은 AC-01 구현 누락·수정 필요, human-review는 AC-02 근거 부족·필요 증거. 어느 것도 pass로 바꾸지 않음 | 직접 대조 통과 |
| RV-16 | 필요 계약 누락 | 검토 A·문서 D 소스 불변/원격 확인 → A 검토와 D 증거 구분 → 신규·재확인 / A 검토 HEAD 유지, D 문서 permalink 사용, 문서 속 A 실행 대상 대조. 없는 A/review URL 없음 | 직접 대조 통과 |
| RV-17 | 필요 계약 누락 | A HEAD·결과·위험·승인 확인 → C1 검토와 확인 종류 구분 → 확인 신규·재조회 / C1 연결·A 일치·위험·승인 상태 최소 요약, 상세 AC/전문 복제·실제 머지 없음 | 직접 대조 통과 |

구현 중 발견한 HEAD 불일치 확인 댓글 경로 충돌을 보완했다. RV-11에서 검토 HEAD와 실제 PR HEAD를 구분한 보류 댓글은 허용하고, 새 HEAD pass·머지 승인은 만들지 않는지 다시 대조했다.
