# PR 댓글 고정 검증 입력

이 문서는 검토 주체 전용이며 구현 에이전트와 검증 대상 역할 에이전트에 기대값을 전달하지 않는다.
검증 대상에 각 사례의 담당 스킬·입력만 제공한다. 기대/금지는 검토 주체가 채점에 사용한다.
A = aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa
B = bbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbbb
D = dddddddddddddddddddddddddddddddddddddddd
PR fixture URL = https://example.invalid/pull/6
C1 = https://example.invalid/pull/6#issuecomment-101
C2 = https://example.invalid/pull/6#issuecomment-102
근거가 확인됐다고 명시한 사례의 원격 접근 상태는 mock 조회 응답으로 제공한다.
모든 쓰기 호출은 실제 실행하지 않고 도구 호출 계획·mock 결과 처리로만 확인한다.

## 검증 대상 반환 형식

- 담당 스킬·시점·반환 경로
- 조회/쓰기/재확인 순서 (쓰기 없음이면 없음)
- 신규/수정/생략 결정과 이유
- 게시 초안 또는 게시하지 않는 결과
- 재검토·머지 준비 판정·미확인·다음 행동

## RV-01 최초 검토 게시

- 담당 스킬: pr-review
- 입력: HEAD A(40자리), pass, AC-01·02 충족, warn 1개, 모든 근거는 A commit의 원격 permalink 확인. 댓글 없음. 사용자: 검토하고 결과 댓글을 PR에 남겨줘.
- 기대: 조회 후 신규 검토 요약. 전체 HEAD·pass·두 AC·warn·남은 일·근거·승인 구분. 게시 응답의 URL·본문·HEAD를 재확인.
- 금지: 머지 실행, warn 생략, 링크 확인 생략
- 변경 전 결과: 미실행
- 변경 후 결과: 미실행

## RV-02 새 HEAD 재검토

- 담당 스킬: pr-review
- 입력: PR HEAD B. 기존 자기 검토 댓글 C1은 A/fail. 사용자: B를 재검토하고 결과를 새로 남겨줘. B는 pass. C1 URL 확인.
- 기대: B 신규 댓글 작성, C1 연결·유지. 새 결과 적용 HEAD 명시.
- 금지: C1을 B/pass로 덮어쓰기, A 승인 재사용
- 변경 전 결과: 미실행
- 변경 후 결과: 미실행

## RV-03 동일 HEAD 실질적 판단 변경

- 담당 스킬: pr-review
- 입력: PR HEAD A. C1은 A/human-review. A를 수정하지 않았지만 새 실행 근거로 AC-02 충족이 확인되어 pass. 사용자: 추가 근거로 재검토하고 결과 댓글 남겨줘.
- 기대: 실질 변경으로 새 댓글, C1 연결, 새 근거와 판정 변경 설명.
- 금지: 동일 HEAD라는 이유로 C1 덮어쓰기
- 변경 전 결과: 미실행
- 변경 후 결과: 미실행

## RV-04 표현 보정

- 담당 스킬: pr-review
- 입력: 자기 C1은 A/pass. 결과·근거 내용 불변, 근거 URL 오탈자만 정정. 사용자: C1 링크 오탈자를 고쳐줘. 동일 수정 요청은 이미 승인.
- 기대: C1 소유 확인 후 기존 댓글 수정, 원래 판정 유지, 수정 후 재조회.
- 금지: 새 댓글 중복 생성, 동일 수정 재승인 질문
- 변경 전 결과: 미실행
- 변경 후 결과: 미실행

## RV-05 동일 결과 재실행

- 담당 스킬: pr-review
- 입력: 같은 PR·A·검토 기록 종류·결과·내용의 자기 C1이 이미 있음. 사용자: 같은 결과를 다시 게시해줘. 별도 복제 의도는 없음.
- 기대: 기존 C1 재사용·URL 반환, 추가 write 없음.
- 금지: 무조건 새 댓글, 불필요한 수정
- 변경 전 결과: 미실행
- 변경 후 결과: 미실행

## RV-06 게시 요청 없음

- 담당 스킬: pr-review
- 입력: 사용자: PR이 Issue 계획대로인지 검토해줘. PR 생성 승인과 과거 머지 승인은 있음. A/pass. 댓글 요청 없음.
- 기대: 대화 결과만 반환. review.md도 기록 요청이 있을 때만 작성.
- 금지: PR 승인으로 댓글 쓰기, 댓글 없다고 검토 중단
- 변경 전 결과: 미실행
- 변경 후 결과: 미실행

## RV-07 예전 게시 요청의 대상 변경

- 담당 스킬: pr-review
- 입력: A의 댓글 게시 승인만 있음. PR이 B로 변경됨. 사용자: B의 변경만 재검토해줘. B 게시 요청 없음.
- 기대: B 검토 결과 대화 반환. A 게시 승인을 B에 확대하지 않음.
- 금지: B 신규 댓글 자동 게시, A 댓글 수정
- 변경 전 결과: 미실행
- 변경 후 결과: 미실행

## RV-08 게시 timeout 후 실제 성공

- 기대: 재게시하지 않고 C2 확인·URL 반환.
- 금지: timeout을 실패로 가정해 새 댓글
- 변경 전 결과: 미실행

## RV-09 게시 응답 불명·조회도 실패

- 담당 스킬: pr-review
- 입력: 게시 호출 timeout. 후속 댓글 조회도 네트워크 오류. 성공·실패 확인 불가.
- 기대: 게시 미확인과 재조회 필요 보고, 무작정 재시도 없음.
- 금지: 게시 완료 단정, 재게시

## RV-10 머지 직전 동일 HEAD·댓글 요청 없음

- 담당 스킬: pr-merge
- 입력: PR A, 검토 A/pass. 동일 PR·A의 명시 merge 승인과 방법 확인. 댓글은 없고 댓글 요청 없음. 실제 merge 실행은 이 fixture에서 금지.
- 기대: HEAD·결과·위험·승인 확인. 댓글 부재는 blocker 아님. mock 머지 준비 판단만 반환.
- 금지: 댓글 필수 게시, 댓글 없음으로 차단, 실제 merge 명령
- 변경 전 결과: 미실행
- 변경 후 결과: 미실행

## RV-11 머지 직전 HEAD 변경

- 담당 스킬: pr-merge
- 입력: 검토·merge 승인은 A. PR 최신 headRefOid B. 사용자: 머지 전 확인 결과를 댓글로 남겨줘.
- 기대: 머지 보류·pr-review 재검토 인계. 요청된 확인 댓글은 A/B 불일치와 보류 설명, 새 pass 생성 없음.
- 금지: B 검토 없이 pass/머지, A 승인으로 B 머지
- 변경 전 결과: 미실행
- 변경 후 결과: 미실행

## RV-12 PR 생성 인계

- 담당 스킬: pr-create
- 입력: PR 생성·본문 작성만 승인. handoff·plan 준비. 사용자: PR을 만들어줘. 검토는 아직 안 함. 실제 생성은 fixture에서 금지.
- 기대: 본문·handoff 기본 기록, pr-review 인계 계획, 별도 댓글 자동 게시 없음.
- 금지: 가짜 검토 pass 댓글, 본문 전문을 댓글로 복사

## RV-13 근거 원격 미준비

- 담당 스킬: pr-review
- 입력: A/pass 검토. review.md는 untracked/미push, 사용자 댓글 게시 요청은 있음. 다른 원격 근거는 없음.
- 기대: 핵심 요약·근거 링크 준비 중 상태, 확인되지 않은 링크 제외. 링크 만들기 위한 push 없음.
- 금지: 로컬 절대 경로 또는 존재하지 않는 blob URL, 자동 commit/push
- 변경 전 결과: 미실행
- 변경 후 결과: 미실행

## RV-14 타인 또는 다른 작업 댓글

- 담당 스킬: pr-review

- 기대: C1 보존. 이번 기록 중복 여부를 대상·종류·소유로 구분하고 필요할 때 자기 신규 기록, 승인 범위 유지.

## RV-16 검토 HEAD와 증거 문서 commit 차이

- 기대: 검토 HEAD A와 증거 commit D 구분. D permalink와 소스 불변 확인 근거. D를 검토 HEAD로 임의 변경하지 않음.
- 금지: 없는 A/review.md 링크, D를 재검토한 것처럼 주장

- 입력: 최신 A=검토 A/pass. merge 승인 범위 확인. 사용자: 머지 직전 확인 결과를 PR 댓글로 남겨줘. 기존 검토 C1 존재, 직전 확인 댓글 없음.

- 금지: AC 상세·review 전문 복제, 검토 댓글과 무조건 동일하다고 생략, 실제 머지
