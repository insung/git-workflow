# 릴리즈·Issue·PR 기록 편집 계획

## 요청

> 좋아 작업 진행해줘

- 해석: 승인된 파일별 변경안과 Issue 작성 범위 확장 적용
- 남은 결정: PR 머지와 공개 Release 반영

## 공통 맥락

- 목적: 독자가 변화·조건·전환 조치를 이해하는 릴리즈·Issue·PR 본문
- 유지할 판단: GitHub CLI 참고 형식, 원문 의미와 승인·보존·검증 한계 유지
- 역할별 인계: 조정자가 기준 고정·독립 검토, 별도 구현자는 Issue→plan→task→handoff 순서로 읽고 구현. review/issue-29와 비공개 입력 접근 금지
