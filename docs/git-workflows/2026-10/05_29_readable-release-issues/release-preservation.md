# 릴리즈 원문 보존 대조

대상은 변경하지 않은 release-source.json의 body다. 아래 원문 행 번호는 각 body 문자열의 행 번호이며 JSON 파일의 행 번호가 아니다. 구현자가 원문과 개정 초안을 직접 대조한 편집 근거이며 독립 판정은 별도다. 제목·문체·배치만 개정하며 당시 동작·승인·전환·검증 한계는 유지한다.
