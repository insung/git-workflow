# 릴리즈 노트 초안

# v1.2.0 — 재시도 안내와 호출명 전환

network 오류에서 재시도 방법을 확인할 수 있다. 안내 호출명은 retry-guide로 바뀐다.

## 기능·개선

- network 오류에서 재시도 방법을 안내한다.

## 수정

- expired 오류의 기존 안내를 유지한다.

## 전환 안내

- retry-help 호출을 retry-guide로 바꾼다.
- 자동 재전송은 포함하지 않는다.
- AGENTS.md 변경은 정확한 경로·변경 전문·적용 위치 승인 후 적용한다.

## 검증과 근거

- 가상 git-workflow 릴리즈의 범위는 이전 공개 v1.1.0부터 이번 v1.2.0까지다.
- 제공된 회귀 검사 결과는 8/8 통과다.
- 실기기 검증은 미실행이다.
- 제공된 변경만 근거로 삼았다. 확인된 PR·커밋 링크는 제공되지 않았다.

## 목표

결제 화면의 network 오류에서 재시도 안내를 제공한다. 사용자는 비행기 모드를 켜고 결제를 선택했을 때 “처리 실패”를 목격했다.

## 기대 동작

- network 오류에서 재시도 방법을 안내한다.
- expired 오류의 기존 안내를 유지한다.

## 실제 동작

- 사용자가 “처리 실패”를 목격했다.

## 재현 절차

사용자가 목격한 절차다. 독립적인 재현 결과는 미확인이다.

1. 앱 v2.1의 결제 화면에서 비행기 모드를 켠다.
2. 결제를 선택한다.
3. “처리 실패”를 확인한다.

## 확인 환경

- 확인 날짜: 2026-10-02
- 앱 버전: v2.1
- 화면: 결제 화면
- 조건: 비행기 모드 활성화

## 영향 범위

포함

- 결제 화면에서 network 오류의 재시도 안내를 제공한다.

제외

- 자동 재전송은 제외한다.
- 서버 변경은 제외한다.

호환성·운영 영향
