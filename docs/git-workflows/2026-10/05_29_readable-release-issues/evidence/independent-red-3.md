## 목표

업로드한 파일이 검색 결과에 표시되도록 한다. 보고된 증상은 “after upload file absent from search”이다.

## 기대 동작

업로드한 파일이 검색 결과에 표시된다.

## 실제 동작

업로드한 파일이 검색 결과에 표시되지 않는다.

## 재현 절차

미확인이다. 파일 업로드 후 검색 결과에 파일이 없다는 증상만 제공되었으며 목격자가 확인한 상세 단계와 검색어는 제공되지 않았다.
