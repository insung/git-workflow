network 오류에서 재시도 방법을 확인할 수 있다. 안내 호출명은 retry-guide로 바뀐다.

## 기능·개선

- network 오류에서 재시도 방법을 안내한다.

## 수정

- expired 오류의 기존 안내를 유지한다.

## 전환 안내

- AGENTS.md 변경은 정확한 경로·추가 전문·위치 승인 후 적용한다.

## 검증과 근거

- 실기기 검증은 미실행이다.
- 가상 작성 범위는 이전 공개 v1.1.0부터 이번 v1.2.0까지다. 제공된 변경만 근거로 사용했다.

# 버그 Issue 초안

## 목표

결제 화면의 network 오류에서 재시도 안내를 제공한다. 사용자는 비행기 모드에서 결제를 선택했을 때 “처리 실패”를 목격했다.

## 기대 동작

network 오류에서 재시도 방법을 안내한다.

## 실제 동작

## 재현 절차

사용자가 목격한 절차는 다음과 같다.

1. 앱 v2.1의 결제 화면에서 비행기 모드를 켠다.
2. 결제를 선택한다.
3. “처리 실패”를 확인한다.

## 확인한 환경

- 사용자 확인일: 2026-10-02
- 앱 버전: v2.1
- 화면: 결제 화면
- 조건: 비행기 모드 활성화

포함
