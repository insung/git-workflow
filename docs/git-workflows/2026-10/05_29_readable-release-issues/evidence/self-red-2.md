# (2) 기능 Issue 초안

제목: feat(payment): network 오류에 재시도 안내 제공

## 변경 의도

network 오류에 재시도 안내를 제공해 사용자가 앱을 재시작하는 상황을 줄인다. 사용자는 network 안내가 없어 앱을 재시작하며, 오류에 맞는 안내를 원한다.

## 영향 범위

- 포함: network 오류의 재시도 안내
- 유지: expired 오류의 기존 안내
- 제외: 자동 재전송
- 제외 이유: 중복 결제 위험에 따른 사용자 승인 결정
