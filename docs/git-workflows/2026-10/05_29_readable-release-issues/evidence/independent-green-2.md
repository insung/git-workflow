## 기능·개선

- 설치할 설정을 선택할 수 있다. 관련 변경: PR #40.

## 수정

- 설치 과정에서 기존 파일을 보존한다. 관련 변경: PR #40.

## 설치·전환 안내

- 대상 제품은 git-workflow이며, 범위는 v1.0.0..v1.1.0이다.

# issue-create 기능 초안

제목: feat(file-search): 업로드 완료 파일의 이름 검색

## 목표

업로드가 완료된 파일을 이름으로 검색해 찾을 수 있도록 한다.

## 영향 범위

포함

- 업로드가 완료된 파일의 이름 검색 기능을 제공한다.

제외

- 파일 삭제 기능은 제외한다.

호환성·운영 영향

- 기존 파일 다운로드 동작을 유지한다.
- 데이터·운영 영향은 구현 방식 결정 후 확인이 필요하다.

## 달성 조건

- [ ] AC-01: 업로드 완료 파일을 이름으로 검색하면 해당 파일 표시
- [ ] AC-02: 기존 파일 다운로드 동작 유지

## 지금 알고 있는 것

- 구현 방식은 미정이다.
- 현재 검색 동작과 검색 화면·API 경로는 미확인이다.

초안 상태: 로컬 초안. 원격 Issue 생성·중복 확인·라벨 조회는 미실행이다. enhancement는 라벨 후보이며 미적용이다. assignee login은 미확인·미적용이다. 구현 방식 결정이 남아 있다.

# issue-create 버그 초안

제목: fix(file-search): 업로드 후 검색 결과의 파일 누락 해소

## 목표

업로드 후 파일이 검색 결과에 나타나지 않는 문제를 해결한다. 업로드한 파일이 검색 결과에 표시돼야 한다.

## 기대 동작

업로드한 파일이 검색 결과에 표시된다.

## 실제 동작

사용자가 보고한 증상은 “after upload file absent from search”다. 업로드 후 파일이 검색 결과에 나타나지 않는다.

## 재현 절차

목격한 상세 재현 절차는 제공되지 않았다. 파일 업로드 후 검색 결과에서 파일이 보이지 않는다는 상황만 제공됐다.

1. 업로드 방법·대상 파일: 미확인
2. 업로드 완료 확인 방법: 미확인
3. 검색 화면·검색어·조회 시점: 미확인

## 확인한 환경

- 확인한 날짜: 미확인
- 화면 또는 API 경로: 미확인
- 배포 버전 또는 브랜치: 미확인
- 실행 환경: 미확인

## 영향 범위

포함

- 업로드 후 검색 결과에서 해당 파일이 누락되는 증상을 다룬다.

제외

- 별도 기능 초안의 이름 검색 기능 추가는 이 버그의 수정 범위와 구별한다.

호환성·운영 영향

- 영향받는 사용자·소비자와 데이터·운영 영향은 미확인이다.
- 유지해야 할 기존 정상 동작은 조사 후 구체화가 필요하다.

## 달성 조건

- [ ] AC-01: 파일 업로드 후 검색 결과에 해당 파일 표시

## 지금 알고 있는 것

- 원인은 미확인이다.
- 로그와 재현 검증 결과는 제공되지 않았다.

초안 상태: issue-incomplete. 상세 재현 절차·검색 위치·확인 날짜·환경과 기존 정상 동작의 보존 조건 확인이 필요하다. 원격 Issue 생성·중복 확인·라벨 조회는 미실행이다. bug는 라벨 후보이며 미적용이다. assignee login은 미확인·미적용이다.
