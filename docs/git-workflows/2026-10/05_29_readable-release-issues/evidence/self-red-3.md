# git-workflow v1.2.0 릴리즈 노트 초안

network 오류에서 재시도 안내를 제공한다. 이전 공개 버전 v1.1.0 이후 제공된 변경만 반영한 가상 초안이다.

## 기능

- network 오류 발생 시 재시도 안내 제공
- expired 오류의 기존 안내 유지
- 자동 재전송 제외

## 호출명 변경

- 안내 호출명 `retry-help`에서 `retry-guide`로 변경
- 기존 `retry-help` 호출을 사용하는 경우 `retry-guide`로 전환 필요

## 검증

- 제공된 회귀 검사 결과: 8/8 통과
- 실기기 검증: 미실행
- 태그·Release 발행 및 배포 결과: 미확인

## 적용 조건

AGENTS.md 변경은 정확한 대상 경로, 변경 전문, 삽입 위치를 제시하고 승인받은 뒤 적용한다. 대상 경로·전문·위치는 제공되지 않아 이 초안에서 확정하지 않는다.
