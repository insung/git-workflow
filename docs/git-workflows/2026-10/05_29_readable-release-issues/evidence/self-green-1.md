# 버그 Issue 초안

제목: fix(payment): network 오류의 재시도 안내 누락 수정

## 목표

결제 화면에서 network 오류가 발생하면 재시도 안내를 제공한다. 사용자는 비행기 모드를 켜고 결제를 선택했을 때 “처리 실패”를 목격했다.

## 영향 범위

포함

- 결제 화면의 network 오류 재시도 안내를 수정한다.

제외

- 자동 재전송은 제외한다.
- 서버 변경은 제외한다.

기존 동작 보존

- expired 오류의 기존 안내를 유지한다.

## 달성 조건

- [ ] AC-01: network 오류에서 재시도 안내 제공
- [ ] AC-02: expired 오류의 기존 안내 유지

## 기대 동작

network 오류에서 재시도 안내를 확인할 수 있다.

## 실제 동작

사용자는 “처리 실패”를 목격했다.

## 목격한 재현 절차

1. 앱의 결제 화면에서 비행기 모드를 켠다.
2. 결제를 선택한다.
3. “처리 실패”를 확인한다.
