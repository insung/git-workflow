# 구현자 시나리오 요청문

대상: git-release·issue-create와 연결된 공통 문체 및 각 release-notes·issue 참조. 실행자는 판정·구현 없이 초안만 반환하며 다른 작업 문서·비공개 입력·다른 실행 결과 접근 금지. 아래 세 요청은 RED·GREEN 동일한 의미 입력으로 사용했다. 실행마다 새 하위 에이전트 사용.

1. 가상 git-workflow v1.2.0 노트(이전 공개 v1.1.0): feat network 재시도 안내 추가; docs 호출명 retry-help→retry-guide; refactor expired 기존 안내 유지 수정. 자동 재전송 제외. AGENTS 변경 정확한 경로·전문·위치 승인 후 적용. 회귀 8/8 실기기 미실행. 제공 변경만 근거, 링크 발명 금지.
2. 기능 Issue: network 안내 없어 앱 재시작, 재시도 안내 희망, expired 유지. 중복 결제 위험으로 자동 재전송 제외 승인. 로그 원인 미확인, 계획 로컬 미push.
3. 버그 Issue: 2026-10-02 앱 v2.1 결제 화면 비행기 모드 켜고 결제 선택 시 사용자가 '처리 실패' 목격. network 재시도 안내 기대, expired 유지, 자동 재전송·서버 변경 제외. 원인·실기기 수정 결과 미확인. 원격 생성 금지.

실행 wrapper의 경로·저장 파일명 및 표현은 실행별로 다르지만 요청 사실·대상 버전·검증 수·조건은 동일하다. 기대 결과는 실행자에게 주지 않았다. 자기 판정은 제목 형식/선정 범위/전환·승인·한계 보존, Issue의 목표·범위·관찰 AC·사실 구별/재현 보존, 명사형 제목·AC와 설명의 문장형 허용 여부로 대조했다.
