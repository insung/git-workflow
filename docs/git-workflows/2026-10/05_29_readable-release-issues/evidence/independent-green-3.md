# v1.1.0 — 설정 선택 설치와 기존 파일 보존

설정을 선택해 설치할 수 있고, 설치 시 기존 파일을 보존한다. 초기화 호출은 old-init에서 init으로 전환한다.

## 기능·개선

- 설치할 설정을 선택할 수 있다.

## 수정

- 초기화 설치 시 기존 파일을 보존한다.

## 설치·전환 안내

- 설치 환경에 Python 3가 필요하다.
- old-init이 제거되므로 기존 old-init 호출을 init으로 바꾼다.

## 검증과 근거

- 범위는 git-workflow의 v1.0.0부터 v1.1.0까지다.
- 설정 선택 설치와 기존 파일 보존은 같은 PR #40의 변경이다. 확인된 URL이 없어 링크는 넣지 않는다.
- 제공된 변경 정보를 바탕으로 작성한 초안이다. 실행 증거가 제공되지 않아 테스트 통과와 배포 완료 여부는 미확인이다.

# 기능 Issue 초안

제목: feat(file-search): 업로드 완료 파일의 이름 검색

## 목표

업로드가 완료된 파일을 이름으로 검색할 수 있게 한다. 기존 다운로드 기능을 유지한다.

## 영향 범위

포함

- 업로드 완료 파일의 이름 검색과 검색 결과 표시를 포함한다.
- 업로드 완료 파일을 찾는 사용자가 대상이다.

제외

- 파일 삭제는 제외한다.

호환성·운영 영향

- 기존 다운로드 기능을 유지한다.
- 데이터와 운영에 미치는 영향은 구현 방식 결정 후 확인이 필요하다.

## 달성 조건

- [ ] AC-01: 업로드 완료 파일의 이름으로 검색 시 해당 파일 표시
- [ ] AC-02: 기존 다운로드 기능 유지

## 지금 알고 있는 것

- 구현 방식은 미정이다.
- 이름 검색의 일치 방식은 제공되지 않았다.

# 버그 Issue 초안

제목: fix(file-search): 업로드한 파일의 검색 결과 누락 해소

## 목표

업로드한 파일이 검색 결과에 나타나지 않는 문제를 해결한다. 검색 시 해당 파일이 표시되어야 한다.

## 기대 동작

- 업로드한 파일이 검색 결과에 표시된다.

## 실제 동작

- 제공된 증상은 업로드 후 파일이 검색 결과에 나타나지 않는 것이다.

## 재현 절차

- 업로드 후 검색에서 파일이 나타나지 않았다는 증상만 제공됐다.
- 목격자가 확인한 상세 절차와 검색어는 미확인이다.

## 확인한 환경

- 확인한 날짜: 미확인
- 화면 또는 API 경로: 미확인
- 배포 버전 또는 브랜치: 미확인
- 실행 환경: 미확인

## 영향 범위

포함

- 업로드한 파일의 검색 결과 누락을 포함한다.
- 업로드한 파일을 검색하는 사용자가 대상이다.

제외

- 검색 결과 누락과 무관한 기능 변경은 제외한다.

호환성·운영 영향

- 데이터와 운영에 미치는 영향은 미확인이다.

## 달성 조건

- [ ] AC-01: 업로드한 파일 검색 시 해당 파일 표시

## 지금 알고 있는 것

- 원인은 미확인이다.
