설치할 설정을 선택할 수 있고, 초기화할 때 기존 파일을 보존한다. 초기화 호출명은 old-init에서 init으로 바뀐다.

## 기능·개선

- 설치할 설정을 선택할 수 있다. 관련 PR: #40.

## 수정

- 초기화할 때 기존 파일을 보존한다. 관련 PR: #40.

## 설치와 전환 안내

- 초기화 실행에 필요한 Python 3 요구사항을 안내한다.
- old-init 호출을 init으로 바꾼다. old-init은 제거됐다.

## 검증과 근거

- 대상 제품은 git-workflow이며, 제공된 범위는 v1.0.0..v1.1.0이다.
- 설정 선택과 기존 파일 보존은 같은 PR #40에 포함된 변경이다. 서로 다른 사용자 결과로 나눠 기록했다.
- 제공된 변경 정보로 작성한 초안이다. 실제 커밋·diff·태그 범위 대조와 테스트 실행 증거는 미제공이다.
- 확인된 PR URL이 없어 링크를 작성하지 않았다.
