# issue-create 기능 초안

제목: `feat(file-search): 업로드 완료 파일의 이름 검색`

상태: local-draft
라벨 후보: `enhancement` · 실제 저장소 라벨 미확인, 미적용
Assignee: 미적용 · 초안 요청으로 실제 계정 미확인

## 목표

업로드가 완료된 파일을 이름으로 검색할 수 있게 한다. 기존 파일 다운로드 동작을 유지한다.

## 영향 범위

포함

- 업로드 완료 파일의 이름 검색
- 검색 결과에서 업로드 완료 파일 확인
- 기존 파일 다운로드 동작 유지

제외

- 파일 삭제 기능

호환성·운영 영향

- 기존 다운로드 동작 유지
- 검색 구현 방식과 데이터·운영 영향 미확정

## 달성 조건

- [ ] AC-01: 업로드 완료 파일의 이름으로 검색 시 해당 파일의 결과 표시
- [ ] AC-02: 기존 파일 다운로드 동작 유지

## 남은 결정

- 검색 구현 방식 미정

# issue-create 버그 초안

제목: `fix(file-search): 업로드 파일의 검색 결과 누락 해소`

상태: issue-incomplete · 재현 절차와 확인 환경 보완 필요
라벨 후보: `bug` · 실제 저장소 라벨 미확인, 미적용
Assignee: 미적용 · 초안 요청으로 실제 계정 미확인

## 목표

업로드한 파일이 검색 결과에 나타나지 않는 증상을 해결한다. 해당 파일이 검색 결과에 표시되어야 한다.

## 기대 동작

업로드한 파일이 검색 결과에 표시된다.

## 실제 동작

제공된 증상은 다음과 같다.

> after upload file absent from search

## 재현 절차

목격자가 확인한 구체적인 재현 절차는 미제공이다.

1. 업로드 수행 절차: 미확인
2. 검색 수행 절차 및 검색어: 미확인
3. 결과 확인 절차: 미확인

## 확인한 환경

- 확인한 날짜: 미확인
- 화면 또는 API 경로: 미확인
- 배포 버전 또는 브랜치: 미확인
- 실행 환경: 미확인

## 영향 범위

포함

- 업로드 파일의 검색 결과 누락 증상
- 파일을 검색하는 사용자

제외

- 관련 없는 기능 변경

호환성·운영 영향

- 데이터·운영 영향 미확인
