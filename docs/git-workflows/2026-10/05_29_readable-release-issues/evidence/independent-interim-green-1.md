# git-release 초안

# v1.1.0 — 선택한 설정 설치와 기존 파일 보존

설치할 설정을 선택할 수 있고 기존 파일은 보존된다. 초기화 호출은 `init`으로 바뀐다.

## 기능·개선

- 초기화할 때 설치할 설정을 선택할 수 있다.

## 수정

- 초기화할 때 기존 파일을 보존한다.

## 설치·전환 안내

- 실행에 Python 3이 필요하다.
- 기존 `old-init` 호출을 `init`으로 바꾼다. `old-init`은 제거됐다.

## 검증과 근거

- 제품은 git-workflow이며 범위는 `v1.0.0..v1.1.0`이다.
- 설정 선택과 기존 파일 보존은 같은 PR #40의 변경이다. 확인된 URL이 제공되지 않아 링크는 넣지 않았다.
- 제공된 변경 정보를 기준으로 작성한 초안이다. 실행·테스트·배포 증거는 제공되지 않았다.
