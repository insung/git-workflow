# issue-create 버그 초안

제목: fix(file-search): 업로드한 파일의 검색 결과 표시

상태: issue-incomplete — 확인 날짜·화면 또는 API 경로·구체적 재현 절차 미확인
라벨 후보: bug — 저장소 내 존재 미확인, 미적용
Assignee: 미적용 — 초안 작성 범위
중복 Issue: 미확인

## 목표

업로드한 파일이 검색 결과에 표시되어야 한다. 현재는 업로드한 파일이 검색 결과에 나타나지 않는다는 보고가 있다.

## 기대 동작

업로드한 파일이 검색 결과에 표시된다.

## 실제 동작

보고된 증상: “after upload file absent from search”

## 재현 절차

구체적인 조작 순서와 검색어는 미확인이다. 보고된 조건은 파일 업로드 후 검색 결과에 해당 파일이 없는 상태다.
