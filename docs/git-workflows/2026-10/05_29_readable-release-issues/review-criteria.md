## 공통 확인

구조 검사는 문장 품질의 증거가 아니다. 원문 주장별 보존 대조와 고정 입력 출력을 평가한다. 공개 Release·main 미추적 .github 변경 없음 확인. 커밋 승인 미확보로 검토 기준은 별도 review 브랜치 작업본에 두고 sha256으로 고정(계획 이탈).
