# 변경 전 독립 결정 시나리오

대상: plan commit 4d356cf (제품 소스는 main 45e2517과 동일). 실행자는 기대 지적 없이 고정 입력 A~E와 기존 스킬만 받음. 세 번 모두 기록.

| 입력 | 관찰 | 판정 |
| --- | --- | --- |
| A | 통합 설치 메뉴가 없어 범위를 재질문 | 새 AC-01 capability 미충족 0/3 |
| B | 일반 라벨 지침으로 누락 생성 가능, YAML 정의 설치 절차 없음 | 기존 일부 지원, 통합 도구 검증 별도 |
| C | 기존 소문자 자산·동의 절 보존과 누락만 설치 | 기존 보존 계약 3/3 |
| D | 정확한 선언 제안 뒤 승인 대기 | 기존 승인 계약 3/3 |
| E | 자동 분류 설정 설치 절차 없음 | 새 AC-05 capability 미충족 0/3 |

실제 파일 복사·원격 라벨 생성·호스트 스킬 자동 호출을 실행한 결과는 아님. 에이전트가 읽은 지시에 따른 결정 결과로 한정.
