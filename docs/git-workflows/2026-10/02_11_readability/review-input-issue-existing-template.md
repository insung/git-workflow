# TC-R02 고정 입력: 기존 Issue 템플릿 우선

새 실행자에게 「입력」과 대상 스킬만 전달해 초안을 받는다. 리뷰 세션이 결과를 판정한다.

## 입력

대상 스킬: issue-create. 외부 접근 없이 아래 조사 완료 자료로 본문 초안만 반환한다.

요청: “실패한 이미지 미리보기를 사용자가 다시 시도할 수 있게 하는 이슈를 짧고 이해하기 쉽게 써줘.”
기존 동일 범위 Issue 없음(조사 완료). 대상 저장소 템플릿의 필수 절은 “## 배경”, “## 영향”, “## 완료 기준”, “## 관련 문서”. 현재 타임아웃에서도 재시도 버튼이 숨겨짐. 원하는 결과는 네트워크 타임아웃에서 버튼 표시. 만료 URL에서는 기존 만료 안내 유지. 자동 재전송은 제외. 데이터 변경 없음. 확인된 디자인 문서 URL 없음. 관련 문서는 내용 없으면 선택 절로 생략 가능. 아직 AC가 없으므로 AC-01·02를 부여한다. 실제 생성·라벨 생성은 요청하지 않음.

## 기대 지적

| ID | 지적 또는 기대 출력 | 근거 | 기대 판정 |
| --- | --- | --- | --- |
| F1 | 기존 배경·영향·완료 기준 절 이름 우선 | 대상 템플릿 | 새 필수 이름으로 일괄 변경하면 fail |
| F2 | 타임아웃 버튼·만료 안내 유지에 각각 검증 가능한 AC ID | 요구 결과 | 사용성 개선 한 줄이면 fail |
| F3 | 자동 재전송 제외·데이터 영향 없음, 빈 관련 문서와 가짜 링크 제거 | 범위 자료 | 필수 범위 삭제 또는 실제 생성이면 fail |

지적하지 않아야 하는 것: 내용 없는 선택 관련 문서 절 생략은 정상. 기능 자체를 구현하지 않음.

## 통과 기준

| 기준 | 조건 |
| --- | --- |
| 필수 | 독립 새 실행자 3회 모두 F1~F3의 기대 동작 충족 |
| 필수 | 지시 변경 전 RED와 변경 후 GREEN의 실제 실행 시점·소스 커밋·출력 기록. 변경 전부터 충족한 동작은 억지 실패를 만들지 않고 유지 증거 기록 |
| 참고 | 글자 수·단어 수 감소는 보조 관찰이며 의미 보존의 통과 근거 아님 |
