## 전달·위험·다음 행동

문서·지시 변경으로 서버 배포는 없다. 기존 설치 템플릿은 보존한다. 롤백은 구현 커밋 revert이며 실행하지 않았다. 원격 문서 미push로 공개 링크를 만들지 않았다. push·PR·머지·Release·설치 갱신은 미승인 범위다. 조정 역할은 최종 HEAD의 독립 검토와 보존 확인 뒤 이번 worktree 정리를 수행한다.
