# TC-R04 고정 입력: 문서 역할과 편집

새 실행자에게 입력 절과 공통 문체·문서 양식만 전달한다. 기대 기준은 전달하지 않는다.

## 입력

외부 게시·파일 수정 없이 다음 자료를 plan·task·review의 짧은 초안으로 나눠 작성한다. 각 초안 뒤 불필요·중복·복합 주장을 편집한다.

Issue #42에 AC-01은 타임아웃 재시도 표시, AC-02는 만료 안내 유지로 정해져 있다. 먼저 오류 분류, 다음 안내 화면을 변경한다. 오류 분류 결정은 unknown에서 기존 안내 유지다. 작업은 분류 구현·표시 연결이며 검증은 network에서 true, expired에서 false다. network 검증 통과, expired 검증 미실행이다. 현재 검토 결론은 human-review이며 다음 행동은 expired 검증이다. 전체 Issue AC와 조사 로그를 모든 문서에 반복해야 하는지 검토한다. unknown에서 기존 안내 유지 결정의 근거는 기존 클라이언트 호환성 보존이다. 이 맥락을 지워야 하는지, 어떤 문서에 남길지 판단한다.

## 기대 지적

| ID | 기대 | 실패 |
| --- | --- | --- |
| F1 | plan은 결정·순서, task는 작업·검증·결과, review는 판정·조치 | 모든 문서에 자료 전체 복사 |
| F2 | 단일 주장·결론 우선·중복 제거를 실제 편집 결과에 반영 | 장문을 표 칸으로 이동하는 것만 수행 |
| F3 | unknown 결정·검증 결과·expired 미실행·human-review·다음 행동 보존 | 간결하게 만들면서 미검증·판정 삭제 |
| F4 | 호환성 유지라는 결정 이유는 plan에 보존·다른 문서 전문 반복 없음 | 중요한 이유를 모두 삭제하거나 각 문서마다 반복 |

## 통과 기준

독립 새 실행자 3회 모두 F1~F4 충족. 지시 변경 전후 각각 실행·소스·결과 기록. 글자 수는 보조 관찰이다.
