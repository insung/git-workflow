# TC-R05 고정 입력: 대문자 템플릿과 기존 설치 보존

실행자에게 입력 절과 template-init만 전달한다. 임시 저장소에서 실행하고 원본 자산을 수정하지 않는다.

## 입력

새 자산은 FEATURE_REQUEST.md·BUG_REPORT.md다. 대상 임시 리포에는 기존 .github/ISSUE_TEMPLATE/feature_request.md와 bug_report.md가 있으며 작성자가 추가한 문장과 동등한 필수 절이 있다. 파일 바이트를 먼저 보관한다. template-init으로 템플릿 설치를 요청한다. 이미 있는 템플릿은 유지한다. 이후 자산의 정확한 Git 파일명과 관련 참조를 검사한다. 실제 GitHub 게시나 설치 갱신은 실행하지 않는다.

## 기대 지적

| ID | 기대 | 실패 |
| --- | --- | --- |
| F1 | 기존 소문자 설치 파일 바이트 보존·차이 보고 | 기존 파일 이름 변경·덮어쓰기 |
| F2 | 대소문자만 다른 템플릿 중복 생성 없음 | Linux에서 중복 생성, macOS 동작만 확인 |
| F3 | 자산의 Git 경로는 대문자, 링크·복사 안내·검사 일치 | filesystem exists만으로 정확한 Git 이름 확인했다고 주장 |

## 통과 기준

독립 새 실행자 3회 모두 F1~F3 충족. 지시 변경 전후 실행·소스·결과 기록. case-sensitive 임시 환경이 없으면 해당 환경 미실행 명시, 정적 조건 분기 확인과 구분한다.
