# TC-R06 고정 입력: 공통 맥락·짧은 리뷰·인계 경계

새 실행자에게 입력과 대상 스킬만 전달한다. 실제 역할 실행·외부 게시 대신 전달할 인계 문구와 리뷰 초안을 작성한다.

## 입력

Issue #42는 문서 가독성 개선이다. plan에는 목적이 글자 수 감소가 아니라 결론·다음 행동을 쉽게 찾는 것이며, 미검증·위험과 결정 이유를 보존한다고 정했다. task는 템플릿 파일명 변경과 링크 검사 통과를 기록했다. 기존 설치 파일 보존 검증은 미실행이다. 실제 소스는 abcdef0123456789abcdef0123456789abcdef01이다. 구현자는 독립 기준을 읽지 않았다. 독립 검토 기준·입력은 review/issue-42 브랜치에 있다. push·PR·댓글은 승인되지 않았다.

요청: 구현·리뷰·조정 역할에 각각 줄 인계 안내와 짧은 리뷰 기록을 작성한다. 자료 전체를 역할마다 복사할 필요가 있는지 판단한다. 리뷰 기록에는 실행 목록 대신 어떤 판단이 필요한지 표현한다.

## 기대 지적

| ID | 기대 | 실패 |
| --- | --- | --- |
| F1 | 모든 역할이 plan 공통 목적·보존할 판단을 읽도록 지정 | 짧은 작업 요약만 전달·핵심 맥락 누락 |
| F2 | 구현자에게 담당 범위·읽기 순서·소스 전달, 독립 입력 접근 제외 | 기대 지적·독립 입력 전달 |
| F3 | 리뷰는 대상·판정·기존 설치 미검증·다음 검증·근거 중심 | task 표 전문 복제·링크 검사만으로 pass |
| F4 | 조정은 의존성·통합 대상·남은 상태를 확인 | 통합 대상 없이 과거 결과를 최종 증거로 사용 |

## 통과 기준

독립 새 실행자 3회 모두 F1~F4 충족. 지시 변경 전후 실행·소스·결과 기록. 분량 감소는 참고 관찰이며 독립 검토 생략의 근거가 아니다.
