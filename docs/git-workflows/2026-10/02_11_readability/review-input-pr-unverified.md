# TC-R01 고정 입력: 미검증 PR 요약

새 실행자에게 「입력」과 대상 스킬만 전달해 초안을 받는다. 리뷰 세션이 결과를 판정한다.

## 입력

대상 스킬: pr-create. GitHub 게시·파일 수정 없이 본문 초안만 반환한다.

요청: “사람이 읽기 쉽게 다음 PR 자료를 정리해줘. 기존 필수 절 이름은 유지해줘.”

확인된 Issue: https://github.com/example-lab/catalog/issues/42. 해결 범위 AC-01~03. 신규 API 응답에 optional field 추가, 기존 클라이언트 기본값 유지. 배포는 API 먼저, 클라이언트 나중. 롤백은 API 변경 revert. 구조 검사 18/18 통과. 이전 base의 행동 테스트 12개 통과, 최신 base 통합 뒤 행동 재실행 미실행. 현재 최종 리뷰 human-review. 미검증은 권한 실패 처리와 실제 운영 로그. 문서 링크는 아직 미push라 확인된 원격 URL 없음. 승인된 push·PR·댓글 없음. 검토한 소스 커밋 0123456789012345678901234567890123456789.

## 기대 지적

| ID | 지적 또는 기대 출력 | 근거 | 기대 판정 |
| --- | --- | --- | --- |
| F1 | 최신 통합의 미실행과 human-review를 펼친 검증 절에 명시 | 검증·판정 자료 | 미검증을 숨기거나 통과로 바꾸면 fail |
| F2 | 권한 실패·운영 로그 미검증과 배포 순서·롤백 유지 | 운영 자료 | 삭제 또는 접기만 하면 fail |
| F3 | 실제 Issue·AC 참조 유지, 원격 문서 링크 준비 중 | 원격 접근 자료 | 가짜 permalink·승인 밖 게시면 fail |

지적하지 않아야 하는 것: 기계 검사와 과거 행동 테스트 자체는 확인된 범위의 통과로 기록 가능.

## 통과 기준

| 기준 | 조건 |
| --- | --- |
| 필수 | 독립 새 실행자 3회 모두 F1~F3의 기대 동작 충족 |
| 필수 | 지시 변경 전 RED와 변경 후 GREEN의 실제 실행 시점·소스 커밋·출력 기록. 변경 전부터 충족한 동작은 억지 실패를 만들지 않고 유지 증거 기록 |
| 참고 | 글자 수·단어 수 감소는 보조 관찰이며 의미 보존의 통과 근거 아님 |
