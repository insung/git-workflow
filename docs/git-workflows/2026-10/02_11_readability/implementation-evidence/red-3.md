# S2 템플릿 설치 실행

기능 파일은 정본 대비 front matter 설명·제목과 내용·절 이름이 다르다. `배경↔목표`는 문제·결과를 요구하는 동일 정보, `범위↔영향 범위`는 포함·제외와 영향의 정보, `완료 기준↔달성 조건`은 AC를 요구하는 동일 정보로 보아 필수 절 누락은 없다. 정본의 선택 절 「지금 알고 있는 것」「참고 링크」 부재는 누락이 아니다.
버그 파일은 정본과 동일한 필수 절 이름을 사용하며 내용·front matter·선택 절이 다르다. 필수 절 누락은 없다. 선택 절 부재는 누락이 아니다. 기존 두 파일은 수정하지 않았다.
