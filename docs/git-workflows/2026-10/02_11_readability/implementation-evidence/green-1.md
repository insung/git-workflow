런타임 증거 확보 불가 영역은 human-review가 필요한 한계다. 정적 검토 가능 여부를 AC 충족으로 해석하지 않는다. 실제 보완 후 새 HEAD에서 재검토한다. 공개 지적에는 비공개 입력·기준을 넣지 않는다. 머지 승인은 별도다.

## 역할별 인계

| 역할 | 읽기 순서 | 담당 범위·다음 행동 |
| --- | --- | --- |
| 구현 | Issue → plan 공통 맥락·결정·단계 → task 01 → handoff·공개 review | 오류 분류·안내 및 AC-02 테스트 보완, 현재 HEAD 재검증 후 task 02에 전달 |
| 리뷰 | Issue → plan 공통 맥락 → diff·task·handoff → 별도 고정된 독립 기준·입력 | def5678 증거 한계 확인, 보완된 새 HEAD에서 독립 검토 |
| 조정 | Issue → plan → 구현·리뷰 결과 | 01 → 02 의존성 관리, 실행 환경·증거 확보 담당 배정, 결과 통합 |

공통 목적과 중복 결제를 막는 안내 전용 결정은 plan 공통 맥락·결정 기록에서 읽는다. 구현 역할은 리뷰 브랜치·worktree·비공개 기준·입력을 읽지 않는다. 현재 구현 변경은 보고됐지만 검증과 독립 검토·전달은 완료되지 않았다. 원격 게시·커밋·push·PR·머지·배포는 이 작성 연습의 승인 범위에 없다.

# S2 임시 저장소 설치 실행 결과

실행 저장소: <temporary-path>

`git init -q`로 임시 저장소를 만든 뒤 시나리오 문자열의 줄바꿈을 실제 LF로 해석해 UTF-8 바이트로 두 파일을 작성했다. 루트·remote·브랜치·작업본을 확인했다. 브랜치는 main, remote 출력은 비어 있고 작업본 상태는 `?? .github/`였다. 커밋·네트워크 명령은 실행하지 않았다.

기존 파일명을 대소문자 무시 비교로 확인하고 두 Issue 파일을 유지했다. PR 템플릿만 스킬 정본에서 복사했다. 각 Issue 파일에 `diff -u`를 실행했으며 내용과 안내 주석의 차이를 확인했다.

## 설치 파일과 바이트 대조

| 파일 | 처리 | 전후 바이트 | 바이트 대조 |
| --- | --- | --- | --- |
| .github/ISSUE_TEMPLATE/feature_request.md | 기존 이름·내용 유지 | 165 → 165 | 같음 |
| .github/ISSUE_TEMPLATE/bug_report.md | 기존 이름·내용 유지 | 239 → 239 | 같음 |
| .github/PULL_REQUEST_TEMPLATE.md | 새 복사 | 스킬 정본과 동일 | 같음 |

최종 파일은 위 세 파일뿐이다. FEATURE_REQUEST.md와 BUG_REPORT.md 대문자 중복 파일은 추가하지 않았다.

- feature_request.md SHA-256: 2085f75f5974e3969db5f67ced3b2e68cf61ead30c3336b67d860e0a78dce724
- bug_report.md SHA-256: 4112a24b6617e0e71f31cf82e7f745bfe14310e0d58fb730c74ffbccbcd8a9ce

## 기존 내용과 정본의 차이

기능 파일은 name·about·title 내용이 다르며 정본 안내 주석과 선택 절이 없다. bug 파일도 name·about·title이 다르고 정본의 안내 주석과 선택 절이 없다. 두 파일의 enhancement·bug 라벨 문자열은 유지됐다. 선택 절이 없는 것은 필수 절 누락이 아니다.

| 기존 기능 절 | 정본 절 | 대응 근거 |
| --- | --- | --- |
| 배경 | 목표 | 문제와 요청 설명을 담는 자리 |
| 범위 | 영향 범위 | 작업 범위를 담는 자리 |
| 완료 기준 | 달성 조건 | AC-01 사용자 기준을 담는 자리 |

기능 파일의 위 세 절은 같은 정보를 요구하는 것으로 보고 필수 절 누락으로 기록하지 않았다. 버그 파일은 목표·기대 동작·실제 동작·재현 절차·확인한 환경·영향 범위·달성 조건의 정본 제목을 모두 사용한다. 필수 front matter name·about·title·labels도 두 파일에 모두 있다. 판단 보류 항목 없음.

라벨 미확인: remote 없음. 라벨 조회·생성·변경은 실행하지 않았다. 설치 결과는 미커밋 로컬 파일이며 push·외부 게시 없음.
