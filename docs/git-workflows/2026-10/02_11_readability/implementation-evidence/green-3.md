정적 검토 가능과 실행 증거 충족은 다르다. pass로 올릴 수 없다. 수정 뒤 새 HEAD를 고정해 재검토한다. 검토 결과는 머지 승인이 아니다. 비공개 입력을 공개 인계에 포함하지 않는다.

## 역할별 인계

| 역할 | 읽을 순서 | 담당 경계 | 다음 행동 |
| --- | --- | --- | --- |
| 구현 | Issue → plan 공통 맥락·결정·단계 → 담당 task → handoff·공개 review 지적 | 오류 분류·안내 문구·assertion; 서버·재전송 제외 | AC-02 assertion 추가 및 현재 HEAD 재검증 |
| 리뷰 | Issue → plan 공통 맥락 → 현재 diff·task·handoff → 독립 기준·입력 | 독립 대조·실행 증거 확인 | 새 HEAD 고정 후 테스트 누락·사용자 화면 증거 재검토 |
| 조정 | Issue → plan → 구현·리뷰 결과 | 의존성·범위·통합 상태 | 01 보완 → 02 증거 → 리뷰 순서 관리 |

공통 목적과 유지할 결정의 정본은 plan.md의 공통 맥락이다. 현재 HEAD는 def5678이다. 모듈·문구 변경은 기록상 완료, 현재 검증·expired assertion·실기기 재현은 미완료다. 구현자에게 독립 검토 입력은 전달하지 않는다. 조정 담당은 로컬 초안을 원격 링크로 꾸미지 않고 실제 외부 행동 전에 해당 승인과 실제 Issue를 확보한다.
