# 선택적 구현 인계

PR 본문 또는 PR 생성 전 대화/작업용 임시 초안에 다음 정보를 전달한다. 별도 handoff.md는 필수가 아니다. 독립 역할의 실행 환경·복잡한 재현을 전달할 때만 파일을 만든다. 기존 handoff.md도 계속 읽는다.

- 실제 Issue URL·담당 AC·공개 계획과 담당 경계
- base/코드 commit·검토 HEAD, 미커밋 파일과 patch 또는 digest
- AC별 구현 위치·기대/실제·검증 방법과 대상·환경·시각·미실행 이유
- 중요한 선택과 이유, 계획/제약 이탈·승인, 범위 밖 발견 사항
- 배포 계획과 실제 확인·롤백·남은 조치·승인 범위

원문·목표·AC·계획을 다시 복사하지 않는다. 임시 위치를 원격 근거 링크로 만들지 않는다. 긴 출력과 고유 증거는 [보관 기준](../../git-workflow/references/document-links.md#증거와-실행-로그)을 따른다. 인계 결과는 자기 검증이며 독립 리뷰 판정을 대신하지 않는다. 문서 허브 인계는 [최소 계약](../../git-workflow/references/document-links.md#문서-허브-인계)을 따른다.
