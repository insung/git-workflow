# 템플릿 설치

[workflow-init](../workflow-init/SKILL.md)의 **템플릿 항목만** 적용한다. 일반 통합 선택 질문으로 되돌리거나 AGENTS.md·라벨·릴리즈 설정을 함께 설치하지 않는다.
[템플릿 절차](../workflow-init/references/templates.md)를 읽어 기존 이름·내용을 보존하고 없는 파일만 설치한다. 템플릿 라벨 조회는 가능하며 생성은 별도 요청 범위에서만 한다.
