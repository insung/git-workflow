```markdown
## 재시도 안내와 호출명 전환

일시 오류에서 재시도 방법을 확인할 수 있다. 안내 호출명은 retry-guide로 바뀐다.

## 변경 사항

### 🚀 기능·개선

- **재시도 안내:** 일시 오류에서 재시도 방법을 확인한다. 자동 재전송은 하지 않는다. [#10](https://github.com/example/demo-tool/pull/10)

### 🐛 수정

- expired 오류의 기존 안내를 유지한다. [#12](https://github.com/example/demo-tool/pull/12)

### 📚 운영·기록 개선

- 호출명을 retry-help에서 retry-guide로 변경한다. 이전 호환 진입점은 제공하지 않는다. [#11](https://github.com/example/demo-tool/pull/11)
- 설치 안내의 참조 경로를 수정한다. [#13](https://github.com/example/demo-tool/pull/13)

## 업그레이드 안내

설정의 retry-help 호출을 retry-guide로 바꾼다. 플러그인 갱신으로 소비 프로젝트 설정을 자동 변경하지 않는다. AGENTS.md 변경은 경로·내용·위치의 별도 승인이 필요하다.

## 검증

제공된 회귀 검사 8/8 통과. 실제 호스트 호출·독립 PR 리뷰와 효과 측정은 미실행이다.

**전체 변경:** [v1.0.0 → v1.1.0](https://github.com/example/demo-tool/compare/v1.0.0...v1.1.0)
```

## 준비·출처 불명 사례

- 대상 태그가 미발행: 확인한 커밋 비교를 쓰거나 예정 비교임을 표시하고 발행 완료로 표현하지 않음
- 이전 공개 태그·커밋 기준이 미확인: 전체 변경 링크를 만들지 않고 미확인 이유 기록
- 관련 PR을 조회할 수 없음: 번호·작성자를 추정하지 않고 확인한 Git 근거와 조회 한계 기록
- 분류에 해당하는 변경이 없음: 빈 보안·성능·의존성·기여자 절 생략
- 프로젝트가 별도 공개 제목·언어·템플릿을 지정: 해당 프로젝트 규칙 우선
